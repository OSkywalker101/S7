Course Outcomes (COs):
At the end of the course, the student will be able to:
1. Develop a comprehensive understanding of the fundamental concepts, architecture,
tokenization mechanisms, embeddings, and operational principles of Large Language Models
(LLMs). (PO-1,2,3,4,5,12, PSO-1,2).
25
2. Analyze the pre-processing techniques, token representations, embedding methods, and
contextual language representations used in modern natural language processing systems.
(PO-1,2,3,4,5 , PSO-1,2).
3. Apply prompt engineering strategies and reasoning techniques to effectively control,
optimize, and evaluate text generation using state-of-the-art generative language models. (PO1,2,3,4,5,6,12, PSO-1,2, 3).
4. Design and develop LLM-based applications using Lang Chain by integrating prompt
templates, function calling, document processing, retrieval mechanisms, and workflow
orchestration. (PO-1,2,3,4,5,6, 12, PSO-1,2,3).
5. Evaluate and implement fine-tuning methodologies, instruction tuning, few-shot learning,
named-entity recognition, and performance evaluation techniques for adapting and assessing
generative AI models. (PO-1,2,3,4,5,12 PSO-1,2,3)
